# Grafik Pracy 2.0

Nowa, czysta linia rozwojowa aplikacji Android + Web dla kierowców transportu między magazynami.

## 2.0.0 baseline
- stabilny start Expo
- Android + Web
- tryb gościa
- dashboard
- tygodniowy grafik 7 dni / 2 zmiany
- generator rotacji
- ręczna zmiana pracownika
- magazyny
- stawki 10 h / 12 h
- podsumowanie wynagrodzeń
- zapis lokalny
- testy rdzenia
- GitHub Actions: test + Web + debug APK

Kolejne moduły: Firebase i synchronizacja → ledger rozliczeń → GPS → statusy → raporty → powiadomienia → czat → eksport → widgety.
